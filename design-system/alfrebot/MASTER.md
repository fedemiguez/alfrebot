# Alfrebot — dirección visual

Basado en ui-ux-pro-max (Minimalism & Swiss + terracota/crema).

## Tokens

| Token | Valor | Uso |
|---|---|---|
| Fondo | `#FFFBEB` | página (papel crema) |
| Tarjeta | `#FFFFFF` + borde `#F2E6E2` | producto |
| Texto | `#0F172A` | cuerpo (~17:1) |
| Primario | `#9A3412` | marca, precios, CTA |
| Acento | `#059669` | estados OK |
| Agotado | `#475569` sobre `#F8F2F0` | cartel |

## Tipografía

- **Lexend** — títulos y precios
- **Source Sans 3** — cuerpo (base ~19px)
- No usar Amatic SC

## Motion

Fade 200ms únicamente. Respetar `prefers-reduced-motion`.
